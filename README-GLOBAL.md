# نشر لعبة المافيا على الإنترنت 🌍

## الأسهل مع الكود الحالي: Render

هذا المشروع يستخدم Node.js + Express + Socket.IO، لذلك أسهل نشر عام هو Web Service يدعم WebSocket. Render يدعم WebSocket من الإنترنت العام، ويعطيك رابط HTTPS عام مثل `https://اسم-الخدمة.onrender.com`.

### الخطوات
1. ارفع مجلد `mafia` إلى GitHub.
2. في Render اختر **New → Web Service** واربط مستودع GitHub.
3. Build Command: `npm install --omit=dev`
4. Start Command: `npm start`
5. Health Check Path: `/health`
6. بعد النشر افتح رابط HTTPS من الهاتف.
7. أنشئ غرفة واضغط زر 🔗. الرابط الذي ينسخ سيصبح مثل:
   `https://اسم-الخدمة.onrender.com/?room=AB12CD`
8. أرسل الرابط لأي شخص في أي دولة، وليس فقط للأجهزة على نفس Wi‑Fi.

### مهم للصوت
يجب استخدام HTTPS عند تشغيل اللعبة على الإنترنت حتى يسمح المتصفح باستخدام الميكروفون. لا تستخدم `http://192.168...` للصوت على الهاتف.

## خيار التوسع العالمي لاحقاً: Cloudflare Durable Objects

إذا أصبحت اللعبة كبيرة وتريد بنية مخصصة لغرف اللعب العالمية، فـ Cloudflare Durable Objects مناسبة جداً: يمكن تخصيص Durable Object لكل غرفة، وهو ينسق WebSockets وحالة الغرفة بشكل متسق. هذا يتطلب تحويل طبقة Socket.IO الحالية إلى WebSockets الخاصة بـ Workers/Durable Objects، لذلك لم أستبدل السيرفر الحالي به في هذه النسخة حتى تبقى اللعبة الحالية تعمل بأقل تغييرات.

## ملاحظة عن الغرف الحالية

الغرف الحالية محفوظة في ذاكرة سيرفر Node.js. إذا أعيد تشغيل السيرفر تختفي الغرف المفتوحة. هذا لا يمنع اللعب عبر الإنترنت، لكنه يعني أن الغرفة يجب أن تُعاد إنشاؤها بعد إعادة تشغيل الخدمة. للنسخة الكبيرة يمكن نقل حالة الغرف إلى Durable Objects/قاعدة بيانات.
