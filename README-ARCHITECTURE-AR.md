# بنية Mafia Online V9

هذه النسخة تجمع وضعين:

1. **محلي:** اللاعبون على نفس Wi‑Fi/Hotspot يتصلون بسيرفر المضيف/الشبكة المحلية.
2. **عالمي:** نفس واجهة اللعبة تعمل عبر عنوان HTTPS عام، وSocket.IO يستخدم للتنسيق، والصوت WebRTC P2P قدر الإمكان.

## الصوت
- WebRTC Mesh مباشر بين اللاعبين.
- STUN مضاف للمساعدة في عبور NAT.
- يمكن إضافة TURN اختيارياً في `window.MAFIA_TURN` إذا أردت نجاح الاتصال حتى في الشبكات المقيدة.
- لا يتم تسجيل الصوت أو حفظه.

## المضيف
- المضيف هو صاحب الغرفة.
- إذا خرج المضيف ينتقل `hostId` إلى أول لاعب متبقٍ.
- صلاحيات كتم/فتح الجميع مرتبطة بالمضيف الحالي.

## الغرف
- لا توجد قاعدة بيانات مطلوبة.
- الغرف موجودة في ذاكرة السيرفر.
- إعادة تشغيل السيرفر تنهي الغرف المفتوحة.

## APK
ملف Android هو WebView/PWA shell. قبل بناء APK النهائي غيّر `GAME_URL` في:
`android/app/src/main/java/com/mafia/game/MainActivity.java`
إلى رابط الموقع HTTPS النهائي.
