# APK + نظام مضيف واحد بدون قاعدة بيانات

هذا المشروع يستخدم **حالة الغرفة في ذاكرة السيرفر فقط** ولا يحتاج MySQL/Firebase/قاعدة بيانات.

## نظام اللعب
- أول شخص ينشئ الغرفة هو المضيف.
- المضيف وحده يبدأ الجولة ويتحكم في المكالمة الصوتية (كتم/فتح الجميع).
- الأدوار والتصويت والليل والنهار تبقى على السيرفر كحالة مؤقتة.
- لا يتم حفظ تسجيلات صوتية؛ الصوت مكالمة WebRTC مباشرة.

## مهم للإنترنت العالمي
لكي يدخل اللاعبون من خارج شبكة المضيف، يجب أن يكون `server.js` منشوراً على عنوان HTTPS عام. لا يمكن لهاتف خلف NAT أن يصبح عنواناً عاماً للعالم كله بمجرد APK ومن دون أي نقطة اتصال عامة.

## APK
مجلد `android/` هو تطبيق Android WebView. قبل البناء، غيّر `android/app/src/main/res/values/strings.xml`:

`https://YOUR-GAME-DOMAIN.example/`

إلى رابط لعبتك العام.

يمكن بناء APK من GitHub Actions عبر Workflow: **Build APK** ثم تنزيل `app-debug.apk` من Artifacts. هذا لا يحتاج قاعدة بيانات.
