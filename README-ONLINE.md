# المافيا أونلاين — نسخة الهاتف

## ما تم تحسينه
- واجهة متجاوبة للهاتف، مع مساحة أكبر للدردشة حتى لا تنقص الرسائل.
- أسماء اللاعبين أكبر وتظهر كاملة على سطرين عند الحاجة.
- التصويت يمكن تغييره قبل انتهاء الوقت.
- زر واضح **↩️ تراجع عن التصويت** لسحب التصويت.
- إذا تعادل أعلى لاعبين في التصويت، تبدأ **إعادة تصويت** بين المتعادلين.
- إذا استمر التعادل في إعادة التصويت، لا يُقصى أحد وتبدأ ليلة جديدة.
- التصويت لا يسمح باختيار اللاعب نفسه أو لاعب ميت.
- اللاعب الميت لا يستطيع التأثير في الدردشة أثناء الجولة.
- ليلاً، قناة المافيا سرية ولا تصل رسائلها إلا لأعضاء المافيا الأحياء.
- شروط الفوز الأساسية: المدينة تفوز عند اختفاء كل المافيا، والمافيا تفوز عند مساواتها أو تجاوزها عدد بقية الأحياء.
- الرسائل الصوتية تبقى متاحة للأحياء مع مراعاة قناة المافيا ليلاً.

## ملاحظة عن القواعد
لعبة Mafia لها نسخ كثيرة تختلف في تفاصيل الأدوار والإقصاء وكشف الأدوار. هذه النسخة تطبق القواعد الأساسية الشائعة: ليل/نهار، أدوار سرية، قتل المافيا، حماية الطبيب، تحقيق الشريف، تصويت نهاري، إعادة تصويت عند التعادل، وشروط الفوز العددية. الأدوار الإضافية الموجودة في المشروع مثل القناص تبقى كقواعد خاصة للنسخة.

## التشغيل
```bash
npm install
npm start
```

افتح:
`http://localhost:3000`

وللعمل من الهاتف عبر الإنترنت، انشر المشروع كـ Web Service على استضافة تدعم Node.js وWebSockets وHTTPS.
